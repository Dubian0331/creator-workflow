PRIVACY POLICY

プライバシーポリシー

更新日：2026年10月12日

Creator Workflow（以下「本アプリ」）は、運営者Dubian0331本人のYouTubeチャンネルを対象とする個人用ツールです。本ポリシーは本アプリと、この説明サイトでのデータの取り扱いを説明します。

1. 取得するデータ

  • Google OAuthで本人が許可したアクセストークン・更新トークンなど、APIに接続するための認可情報。
  • 本人のチャンネルID、動画ID、説明文、公開日時、公開状態など、チャンネルと動画の情報。
  • YouTube Analyticsの再生数、視聴時間、平均視聴時間、平均視聴率、登録者増加数などの標準指標。提供される場合はReporting APIのサムネイル表示回数・クリック率等も取得します。
  • 題材の検討に使うYouTube検索結果と、他チャンネルの動画の公開メタデータ・公開統計。

現在の権限は次の2つです。

  • https://www.googleapis.com/auth/youtube.readonly
  • https://www.googleapis.com/auth/yt-analytics.readonly

Googleのパスワード、支払情報、Gmail本文、収益指標は取得しません。現在の実装ではコメント原文を収集していません。

2. 利用目的

対象チャンネルが本人のものかの確認、公開動画と制作物の照合、公開後の標準指標の確認、次の動画の構成の検討、接続障害の診断に利用します。公開データは題材の調査に利用します。広告配信のための個人プロファイルの作成、データ販売、再生数や登録者数の水増しには利用しません。

3. 保存と保護

認可情報は管理されたクラウド環境の秘密情報設定で管理し、動画、公開サイト、ソース管理、成果物ZIPには含めません。APIの応答はアクセスを限定した専用のデータストアに保存します。制作物やポータブルバックアップにAPIの生データを含めない構成です。アクセストークンはAPI接続処理で使用します。

4. 保存期間

他チャンネルの公開メタデータ・統計は取得時点ごとに最長30日を上限とし、27日以内の更新確認を基準に扱います。本人の認可済み指標には最長365日の上限を設けていますが、27日以内の権限確認ができないデータは参照せず削除対象とします。現在の実装では収集・確認コマンドの実行時に期限を検査して削除します。

常時稼働の削除スケジューラーは開発中です。長期停止・利用終了・削除依頼時には、運営者が専用データストアと関連するAPI参照を削除します。APIデータを含まない自作の原稿・動画・品質確認記録は、制作履歴として別に保存します。

5. 外部サービスとの関係

Google・YouTubeの公式APIと、実行基盤であるクラウド環境を使用します。動画等の自作成果物は運営者の専用Google Driveフォルダに保存する場合があります。

ChatGPT/Codexを制作補助に使用しますが、Googleの認可情報、API応答そのもの、非公開の生指標、コメント原文は制作モデルに送信しません。モデルには自作の原稿・図解・品質確認情報や、ローカル処理で選択した必要最小限の制作変更指示を渡します。YouTubeから取得したデータをAIの汎用モデルの訓練に利用しません。

データの販売や広告目的の第三者への提供は行いません。サービス提供者による処理には、各サービスの契約・プライバシーポリシーも適用されます。

6. 取り消しと削除

Googleアカウントの接続管理から、本アプリへのアクセスを取り消せます。取り消し後は新たな取得ができなくなります。アプリが失効を検出した際には、保存済みAPIデータと改善処理のAPI参照を無効化・削除します。実行停止中を含めて保存データの削除を求める場合は、OAuth同意画面のユーザーサポートメールアドレスへ連絡してください。認証情報やパスワードを連絡に含める必要はありません。

7. この説明サイト

このサイトにはログイン、入力フォーム、広告、独自のアクセス解析、Google OAuthトークンの取得処理はありません。配信サービスは、ページを配信し不正利用を防ぐために、IPアドレスやアクセス日時等の通信情報を処理する場合があります。

8. 適用されるポリシーと変更

Google APIから受け取る情報の利用および他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。YouTube APIの利用にはYouTube API Services利用規約が適用されます。Googleによるデータの取り扱いはGoogleプライバシーポリシーをご確認ください。

データの利用方法を変更する場合は本ページを更新し、新しい権限が必要な場合は本人の同意を取得します。本ページの更新のみでGoogleへのアクセス権限を追加することはありません。
